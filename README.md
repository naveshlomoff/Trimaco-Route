# Trimaco Route

כלי לסידור העבודה של צוות הלוגיסטיקה בטרימקו.

**שלב א׳ (עכשיו):** עדי מדביקה את הודעת הסידור היומית, והמערכת מפרקת אותה למשימות לפי עובד ולומדת את
המקומות. אפשר לייבא גם את ההיסטוריה מקבוצת הווטסאפ. המנהלים רואים לוח עם דפוסים וחפיפות בין נהגים.

**שלב ב׳ (בהמשך):** המלצות לשיפור הסידור, או בניית סידור מרשימת משימות, לפי זמני נסיעה ופקקים.

## פיתוח

```bash
npm install
npm run dev      # http://localhost:5173/?demo  — מצב דמו בלי התחברות
npm test
npm run build
```

האתר עולה ל-GitHub Pages אוטומטית בכל push ל-`main`.
